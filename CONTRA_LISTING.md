## Product description (paste into Contra)

### Sell a warm, premium café website that looks ready to launch

**Cozy Cafe** is a complete, modern, mobile-responsive café website built with **Ruby on Rails**, clean **HTML/CSS**, and **JavaScript (Stimulus)**.

It’s designed for cafés, coffee shops, bakeries, and food businesses that want a cozy, premium online presence — not a generic restaurant template.

### What’s included
- Full multi-page website:
  - Home
  - About
  - Menu
  - Gallery (with lightbox)
  - Contact (validated form + map)
  - Privacy & Terms placeholders
- Sticky header + mobile hamburger navigation
- Popular picks / food cards
- Category menu tabs with price layout
- Testimonials section
- Dark premium footer with social icons
- SEO metadata + local business structured data
- Subtle scroll animations (respects reduced motion)
- Responsive layout for mobile, tablet, and desktop

### Tech stack
- Ruby on Rails 8
- ERB views
- Dart Sass
- Stimulus + Importmap
- No heavy UI frameworks

### Perfect for
- Café / coffee shop websites
- Bakery & brunch brands
- Freelance portfolio demos
- Client starter projects you customize and resell as services

### How to run
```bash
bundle install
bin/rails db:prepare
bin/dev
```
Then open `http://localhost:3000`

### Notes
- Demo branding uses **Cozy Cafe** (Cadillac, MI) as sample content
- Replace business name, address, phone, menu, and images with your client’s details
- Social links and opening hours are placeholders by design
- Menu prices in the demo match the sample project data exactly
